📋 Design Guidelines & Standards
Accessibility
• Minimum contrast ratio: 4.5:1
• Focus states on all interactive elements
• Keyboard navigation support
• ARIA labels where needed
Responsive Design
• Mobile: 375px - 767px
• Tablet: 768px - 1023px
• Desktop: 1024px+
• Flexible grid system
Micro-interactions
• Hover states on buttons (transform +1px)
• Focus ring on inputs (3px blue shadow)
• Loading states for actions
• Smooth transitions (0.3s ease)
Visual Hierarchy
• Primary action: Bold blue
• Secondary action: Muted gray
• Success: Green
• Error: Red
Consistency
• Uniform border radius (8px standard)
• Consistent padding (4px grid)
• Reusable components
• Fixed type scale
Performance
• Optimize image assets
• Lazy load course cards
• Smooth 60fps animations
• Efficient state management
